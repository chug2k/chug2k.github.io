    About this edition

    Charles Lee introduced CoderSchool’s Git workflow chapter on June 17, 2021 (commit 6ee3fea). It directs feature reviews to the development branch. This public exercise builds a new fictional print room around that decision. The files, commits, interface and writing were made for this edition. The kit includes a local Git replay.
