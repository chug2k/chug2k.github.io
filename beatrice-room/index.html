Try a two-view rehearsal
  1. Select 15 seconds · quick rehearsal and choose Create room. Choose Open learner view to open a second tab in this browser.
  2. In the learner tab, choose Join room. In the facilitator tab, choose Open check-in. In the learner tab, choose Ready. Both views now show Planning.
  3. Enter a plan and choose Save plan. When the timer ends, both views show Reflection. The facilitator can choose Open reflection now for an early transition.
  4. In the learner tab enter a reflection, then choose Finish reflection. Both views show Complete. Reload and choose Download session to take the record with you.
Use two devices in a classroom

Download and extract the classroom kit. On the facilitator’s computer run python3 classroom.py --lan with Python 3.8 or newer. Open its LAN address, create a room and copy the learner link to a second device on the same trusted network. Keep the host running. The kit’s guide covers restarting the host and where it stores room records.
