# Workshop illustration

`workshop.webp` was generated for this blog using the Image API and the explicitly requested **`gpt-image-2.5-sunburst`** model on 2026-10-11.

- 1536 × 1024, high quality, transparent WebP, compression 90.
- Generated through the imagegen skill's bundled CLI.
- Final prompt: [`workshop-prompt.txt`](workshop-prompt.txt).
- Original characters in a Futurama-inspired setting: a tinkerer, a robot holding a smoking shoe, and an alien with a pickleball paddle. The human began as an original character; Charles confirmed the resemblance and asked to keep it.
- The API key is held outside this repository and is not needed to run the website.
