Try the timing check
  1. Choose Load radio example under Import subtitles. Select cue 01 and set End (seconds) to 2.250. Choose Apply cue. The sheet now reports one overlap.
  2. Choose Trim overlaps. Cue 01 ends at 2.000 seconds, exactly when cue 02 starts. Undo edit restores the overlap.
  3. Choose Preview timeline to hear the tones and see the active lines. Export SRT saves UTF-8 subtitles. Export tone WAV saves the matching mono track.
