    About this edition
    In October 2023 Charles Lee’s CoderSchool Qwik prototype asked a model to invent a companion and plan three SQL levels. Its interface generated the opening level. This edition keeps the companion-led quest structure. Rill, the mystery, all records, the art and the playable casebook were made for this game. Queries run locally with sql.js 1.17.0, using the SQLite build packaged for Three Cheapest Crossings.
