Drills

Major blocks

1. Split stations (10–35)

25 min Charles feeds Rotate ~6–7 min
  1. Kiwi — High-ball freeze: Feed high floaters to forehand/backhand. Paddle up early. Catch/block — no swing. Count 8 clean freezes before any soft punch.
  2. Jason — Early contact: Feed so bounce meets him rising. Cue prep before bounce. Contact waist/chest. Abort any late drive — soft block instead.
  3. Rotate so each gets two focused rounds. Charles stays feeder; partner shags / shadows on opposite side.

2. Soft game — reset progression + kitchen (35–55)

20 min Paired Charles feeds / joins
  1. Close NVZ catch — soft catch/block at kitchen line (dead hands).
  2. NVZ line block — open face, absorb, no pop-up.
  3. Midcourt lift — from transition: open face, stable wrist, grip 3–4/10, quiet legs, lift with shoulder (not push).
  4. Drop + split + reset — drop in, split step, then reset the next ball.
  5. Stay-alive — keep ball soft until someone earns kitchen; then dink exchanges.
Reset feel

Open paddle · loose grip · shoulder lift

3. Constrained games (65–100)

35 min Scoring on Rules bind soft hands
  1. Kiwi: No speed-ups. Any intentional speed-up = lose point. Soft attacks only via placement.
  2. Jason: Drive contacted late (on the way down) = lose point. Early soft drives OK only if contact is early.
  3. Charles can play as third / feeder-into-points. Rotate sides. Keep rallies kitchen-oriented.

4. Mini scrimmage (100–120)

20 min First 2 = drop/reset
  1. After serve + return, first 2 shots must be drop or reset.
  2. Then play out the point under soft theme (Kiwi still no reckless speed-ups if composure breaks).
  3. Celebrate clean kitchen arrivals over winners.
