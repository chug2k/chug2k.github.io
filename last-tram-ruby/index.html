Open the worked method 
def each
  return enum_for(:each) unless block_given?

  @routes.each do |route|
    route.fetch("trips").each do |trip|
      trip.fetch("stops").each do |stop|
        yield stop
      end
    end
  end
  self
end

Each block takes one step down the timetable. Only the innermost block holds a stop record. The early return creates a cursor for a caller who wants to choose when to advance.
